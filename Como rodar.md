# Como abrir o site — Miguel Franco

1. Extraia a pasta do ZIP.
2. No Windows, dê dois cliques em `abrir.bat` (é necessário ter Python 3 instalado).
3. O navegador abrirá em `http://127.0.0.1:8000`.
4. Para encerrar, volte ao terminal e pressione `Ctrl+C`.

Também é possível executar `py serve.py --open` no terminal, dentro desta pasta.
